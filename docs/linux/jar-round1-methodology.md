辅助站点 JAR 仅注册映射不计实际加载。额外的合成缺失类触发仅验证 loader，记录独立触发方式，不计 captured API、Spider ready 或业务成功。

严格报告器复核冻结文件、原始/语义 manifest 哈希、执行 runner、角色/API/ext、预算、实际 Docker Image/User/退出状态及缺测覆盖；从返回的 sites 重新统计，不直接信任执行报告的汇总。加载成功、初始化 ready、业务非空、空 JSON、无效 JSON、网络、超时、失败和未执行均分列。

同 runtime 中的超时会终止后续调用；后续独立 runtime 的补测必须另立报告。扩大预算的诊断也独立记录，不能改写原预算的结果。首页、分类与详情仅为有限在线观察；它们的参数不是 Android/ART 确定的同参数业务验收。首页推荐、搜索两种签名、分类第二页、筛选和播放解析返回值均未纳入本轮业务测试，留待方案第四轮。
